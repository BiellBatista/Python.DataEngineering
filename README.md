# Python.DataEngineering

Repositório com projetos de estudo em engenharia de dados no ecossistema
Python. Cada projeto tem seu próprio escopo, tecnologias e instruções de uso.

## Projetos

### [Alura-Imersao-Engenharia-Dados-IA](Alura-Imersao-Engenharia-Dados-IA/README.md)

Projeto educacional colaborativo baseado na Imersão Engenharia de Dados da
Alura. Explora dados de voos da ANAC para analisar atrasos, cancelamentos e
pontualidade, com Python, SQL e Databricks. O material inclui etapas de
ingestão Bronze, transformação Silver, qualidade e modelagem Gold.

### [B3-Pipelines](B3-Pipelines/README.md)

Base local e extensível para orquestrar e processar pipelines de dados da B3,
com Airflow, DuckDB/Quack e armazenamento Parquet em um Data Lake. Atualmente,
inclui a pipeline de séries históricas COTAHIST, organizada nas camadas RAW,
Bronze e Silver.

Consulte o README de cada projeto para conhecer pré-requisitos, configuração,
execução e documentação específica.
